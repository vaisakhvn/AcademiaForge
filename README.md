# 🎓 AcademiaForge

**AcademiaForge** is a comprehensive AI-powered study companion designed to help students build better learning habits, optimize focus sessions, and gain actionable insights from their productivity patterns.

Built with a modern web stack and powered by Google's Gemini AI, AcademiaForge goes beyond simple timers and task trackers by delivering personalized strategic recommendations for improved focus, consistency, and retention.

---

## ✨ Features

### 📊 Smart Dashboard

* Visual analytics for:

  * Study hours
  * Focus trends
  * Mood patterns
  * Productivity consistency
* Clean and responsive UI for quick insights.

### 🤖 AI Copilot

* Powered by **Google Gemini AI**
* Generates:

  * Personalized study recommendations
  * Confidence scores for upcoming sessions
  * Focus optimization strategies
  * Retention improvement suggestions

### ⏳ Pomodoro Timer

* Built-in customizable Pomodoro focus timer
* Adjustable:

  * Study duration
  * Break intervals
  * Long break cycles

### 🔬 Habit Researcher

* Analyze long-term productivity and habit trends
* Discover patterns affecting focus and learning efficiency
* AI-assisted behavioral insights

---

## 🛡️ Privacy-First Architecture

AcademiaForge is designed with privacy as a core principle.

### Local-First Storage

* Core user data is stored locally in the browser using `localStorage`
* No mandatory accounts
* No automatic cloud sync
* Instant access without signup

### Optional Persistence

* Users can optionally log in for session continuity
* Secure token-based authentication
* Same-device persistence without compromising privacy

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/vaisakhvn/academiaforge.git
cd academiaforge
```

### 2️⃣ Install Dependencies

```bash
npm install
```

### 3️⃣ Configure Environment Variables

Create a `.env` file in the root directory:

```env
VITE_GEMINI_API_KEY=your_api_key_here
```

### 4️⃣ Start Development Server

```bash
npm run dev
```
